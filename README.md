📈 Stock Portfolio Tracker

A simple Python-based Stock Portfolio Tracker that helps users calculate and manage their stock investments. Users can select stocks, enter quantities, and view the total value of their portfolio.

✨ Features
Stock Price List: Displays a list of available stocks with their sample prices.
Stock Selection: Allows users to choose stocks they want to invest in.
Quantity Input: Lets users enter the number of shares purchased.
Investment Calculation: Calculates the total amount invested in each stock.
Portfolio Summary: Displays selected stocks, quantities, prices, and the total investment value.

🛠️ Built With

Language: Python 3.x
Libraries: Standard Library (csv)

🚀 Getting Started
Prerequisites

Make sure Python is installed on your system. You can check the Python version by running:
python --version

Run the Program
python stock_portfolio_tracker.py
